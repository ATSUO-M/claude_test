# Snake Game 🐍

ターミナルで動くシンプルなスネークゲームです。

## 必要環境

- Python 3.x

## 起動方法

```bash
python3 snake/snake.py
```

## 操作方法

| キー | 動作 |
|------|------|
| ↑ / W / K | 上に移動 |
| ↓ / S / J | 下に移動 |
| ← / A / H | 左に移動 |
| → / D / L | 右に移動 |
| Q | 終了 |

## 難易度

| レベル | 速度 |
|--------|------|
| かんたん | ゆっくり |
| ふつう | 普通 |
| むずかしい | 速い |

## ルール

- 壁または自分の体に当たるとゲームオーバー
- 食べ物(●)を食べるとスコア +10
- ハイスコアはセッション中保持されます
